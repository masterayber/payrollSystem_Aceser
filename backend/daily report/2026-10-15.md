## What changed

### Day 3 open items, now resolved
- **Settings guard (high).** `requireSelfOrAdmin` in `routes/settings.js` now reads `req.params.id`, so employees can save their own settings and profile photo again.
- **Upload order (medium).** On `PUT /users/:id/profile-photo`, the auth checks now run before `upload.single(...)`, so rejected requests no longer write files to `backend/uploads`.
- **Leave status route (medium).** The redundant role check is gone, the enum is now `Disapproved`, and disapproving a leave reverts its On-Leave attendance days (past days become `Absent`, future days are deleted, days covered by another approved leave are left alone).

### Leave route hardening (PR #10)
- `PATCH /api/filing/leave/:id/status` now matches the overtime route: invalid ID returns 400, only `Approved` or `Disapproved` is accepted (400 otherwise), and a leave is decided once using an atomic `Pending` filter (409 if already decided, 404 if missing).
- Added `backend/scripts/migrateLeaveStatus.js`, a one-time script that moves old `Rejected` leaves to `Disapproved`. It is a dry run by default; `--apply` performs the update.

### Repository hygiene and CI
- **`node_modules` untracked.** About 6,600 files from the root `node_modules` were tracked despite `.gitignore`; `main` now tracks none.
- **CI workflow.** On every PR and push to `main`: install root and frontend dependencies, frontend lint, frontend build, and a syntax check on all backend files. The latest run on `main` is green.
- **Lint cleanup.** Small fixes across 11 frontend files to get lint passing, plus the unused `setDeductionsData` in `Deductions.jsx` (state is now `const [deductionsData] = useState({})` until the deductions API exists).
- **Branch protection.** Ruleset `protect-main` is active on the default branch: pull request required (0 approvals, since there is one developer), the `check` job must pass, no branch deletion, no force-push.
